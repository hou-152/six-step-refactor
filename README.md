# six-step-refactor

把「重构一下」变成可复用、可回滚、可验收的动线。适用于有既有资产的 Skill 家族、知识库、Agent 体系等自维护系统的重构；从零新建新 Skill 不适用（那是 skill 制作器的领域）。

核心是一套逆熵判据＋六步流程：

1. **编排定界**——复杂任务先进编排（1 主 ≤ 2 辅），出提示词不接手；授权边界动手前写清。
2. **体检取证**——真源全读、验收脚本全跑、证据分级；结构性病灶要拿文件与日志实锤，读到机制层。
3. **对标定案**——外部系统拆到机制层，加理论与历史同构成败案例，得出条件性标准答案；核心结论通常是「反大爆炸、分步可回滚」。
4. **方案拍板**——冲突列成 C 清单交所有者逐项定；拍板前不动任何共享文件（硬检查点）。
5. **绞杀者落地**——纯增量先行（契约＋字段＋机检）→ 行为级改动走门槛 → 真实事件攒证据 → 数据决定合并与砍除。
6. **对抗闭环**——建成后自己攻击自己：第一性定价每个部件、盲测拿验证等级、与改前版本比对；诚实修正是方法的一部分。

外加五条铁律：唯一真源＋唯一认领人、发前停、验证分级如实报、失败驱动＋证据驱动、每步可回滚。

体检全绿且无失败证据时，它会给出「不重构」的结论——反大爆炸本身就是标准答案。

## 安装

```bash
npx -y skills add hou-152/six-step-refactor -g --all
```

## 使用

安装后对 Agent 说：

> 用 six-step-refactor 重构我的 XX Skill 族：先体检出报告和待拍板清单，拍板前不要动任何共享文件。

## 运行依赖

- 支持 Agent Skills 的客户端；无脚本、无网络、无外部 API 依赖。

## 内容与隐私

本仓库只发布运行这个 Skill 所需的文件；本地评测样本、预期答案和运行记录不包含在公开包中。
